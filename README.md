# wechat-group-daily-report · 微信群聊可视化日报

把指定微信群的聊天记录一键生成固定格式的可视化日报网页（HTML）：每个群一个独立详情页，外加一个汇总页，自动统计消息量、活跃人数、时段分布、发言人排行，并由 AI 提炼「今日大事记 + 今日精华」，最后发布到云托管生成可分享的链接。

> Generated by **笃行者AI** —— 帮你用 AI 重塑日常。

## 功能特性

- 📊 **自动统计**：24 小时消息分布、发言人 TOP 10、消息类型占比、最长单条分享
- 📝 **AI 提炼**：今日大事记时间线（重要事件高亮）+ 按主题分色的精华内容色块（保留人名、数字、原话引用，可回溯）
- 🖼️ **图片解密与识别**（可选模块）：自动推导微信 4.x 图片 AES 密钥（无需内存扫描），批量解密 `.dat` 加密图片，wxgf（HEVC）自动转 PNG
- 🌐 **发布**：HTML 发布到腾讯云 CloudBase 静态托管，每群一个独立链接 + 一个汇总页入口
- 🕐 **增量口径**：自动记录上次生成时间，避免重复统计；支持自定义时间范围

## ⚠️ 使用前提（必读，装依赖解决不了）

本工具读的是**你本机「微信电脑客户端」的本地聊天数据库**，所以下面这条是硬性前提：

> **微信 4.x 电脑客户端必须正在运行、且已登录。**

具体来说：

1. **必须是 Windows + 微信 4.x 电脑客户端**。手机微信、网页版微信、企业微信都不行。
2. **客户端要处于登录状态**。登录后最小化到系统托盘完全没问题，窗口不用停在前台；但**不能退出登录，也不能结束进程**。
3. **目标群要在电脑端可见**。如果某个群只在手机上聊过、电脑端从没打开过，先在电脑上点开该群一次，等聊天记录同步下来。
4. 生成日报期间**别关微信**。中途关掉，拉到一半就会中断。

> 为什么？聊天记录是加密的 SQLite，密钥在客户端登录后才加载。客户端没登录，任何工具都拿不到数据——这不是权限问题，是密钥根本不存在。

`install.py` 启动时会先检查这一项，没开会明确告诉你：

```
✗ 微信电脑客户端  未运行/未登录 —— 需要你打开微信电脑端并登录

  ┌─ 这一步只能你手动做 ─────────────────────────────┐
  │ 打开「微信电脑客户端」并登录，保持登录状态。      │
  │  · 手机微信 / 网页版微信 / 企业微信 都不行        │
  │  · 登录后最小化到托盘即可，窗口不用停在前台      │
  └──────────────────────────────────────────────────┘
```

登录完回 Agent 一句「继续」即可，不用重装任何东西。

## 快速开始

### 第一步：打开微信电脑客户端并登录

见上面「使用前提」。最小化到托盘就行，但别退出登录。

### 第二步：一条命令装齐所有依赖

```bash
python install.py
```

**不需要你判断要装什么。** `install.py` 会自动：检查微信客户端是否登录 → 检查 Python 版本 → 安装 wechat-cli / pycryptodome / playwright / av（默认源失败自动切清华镜像）→ 准备 Playwright 浏览器（Windows 直接用系统 Edge，免下载）→ 首次自动 `wechat-cli init` 提取微信密钥 → 有 npm 时自动安装 CloudBase CLI。幂等设计，重复跑只会补缺失的项。

```bash
python install.py --check   # 只体检不安装
```

如果你是通过 AI Agent（WorkBuddy / Claude 等）使用本 skill，**Agent 会自动执行安装**，你什么都不用装——这也是 SKILL.md 里写死的规则：缺依赖就静默安装，不允许反问你"要不要装"。

### 第三步：对 Agent 说一句话

把整个目录放进你的 Agent 技能目录（如 WorkBuddy 的 `~/.workbuddy/skills/群聊日报/`），然后说：

> 给「马吉私域群」和「朋友圈21天打卡营」做个日报

Agent 会自己定位群、拉记录、统计、提炼、渲染、发布，最后给你一个链接。完整工作流见 [SKILL.md](SKILL.md)。

```bash

python scripts/decrypt_wechat_images.py 2026-11
```

### 图片解密原理（本项目最有意思的部分）

微信 4.x 的图片 `.dat` 不再用数据库密钥，而是 `AES key = md5(code + wxid)[:16]`、`XOR key = code & 0xFF`，其中 `code` 可以直接从 `%APPDATA%/Tencent/xwechat/net/kvcomm/key_<code>_*.statistic` 的文件名拿到——**完全不需要内存扫描**。V2 布局：15 字节头之后，前 `(aes_len & ~0xF) + 16` 字节是 AES-ECB 区，其余整体单字节 XOR。详细过程记录在 [SKILL.md](SKILL.md) 的图片解密章节（包括我们踩过的坑：整个 body 都解 AES 会得到"花屏"假图）。
